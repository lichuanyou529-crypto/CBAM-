## 零、三十秒先搞清楚一件事

**这个网站 = 一个文件夹。**

```
cbam-verifier-board/
├── index.html      ← 网页本体
├── data.json       ← 网页的数据（机构、法规、案例、经验、商机都在这里）
└── qrcode.png      ← 企业微信二维码（没有就用占位框，不影响使用）
```

所谓"部署"，就是把这个文件夹交给一家免费／便宜的托管服务，让它给你一个网址。

**没有任何代码要写，没有任何软件要装，全程在网页上点鼠标。**

> 三条路都输出同一个网站、同一个网址结构，随时可以换，不存在"选错了就白做"。

## 一之二、面向国内客户：选哪一条（先看"备案"这一道坎）

**结论先行：读者、客户都在国内 → 首选乙（腾讯云 COS 静态网站，地域选国内节点）。**
打开最快最稳，公众号"阅读原文"点开不卡顿，每周更新只需重传一个文件。

但落地路径取决于**域名有没有 ICP 备案**——这是唯一的决定性变量：

| 你现在的情况 | 怎么走 | 预计耗时 |
|---|---|---|
| **有已备案的品牌域名** | 腾讯云 COS 建桶（地域选国内，如广州／上海）→ 开启静态网站 → 上传三个文件 → 绑定自有域名 →（可选）接入 CDN | 约 1 小时（含 DNS 生效） |
| **有域名但未备案** | 两条腿走路：①立即用 COS **境外节点（香港／新加坡）**上线，免备案、国内可访问；②同步走企业备案，备案通过后切回国内节点并绑定域名 | 上线当天；备案约 10–20 个工作日 |
| **还没有域名，想先跑起来** | 直接用 COS 分配给你的默认网址（不用买域名、不用备案），先发几期看看效果 | 约 20 分钟 |

**关于备案，记住三句话：**

1. **用云服务商给你的默认网址访问 → 无需备案**（域名本身归属服务商，已由其完成备案）。
2. **一旦绑定自己的域名并解析到境内节点／境内 CDN → 该域名必须完成 ICP 备案**，否则访问会被阻断。
3. **解析到境外节点或境外服务（香港、新加坡、Cloudflare、GitHub Pages）→ 无需备案**，代价是国内访问速度略逊。

> 具体以腾讯云控制台的实时提示与备案指引为准；企业备案需准备营业执照、法人身份证件等材料，由服务商小程序引导完成。

**为什么不把 GitHub Pages / Cloudflare Pages 作为主要投放渠道？**
这两家免费且好用，但服务器在境外，国内网络环境下**延迟高、部分地区偶发打不开**。本榜的主要入口是公众号文章里的"阅读原文"——如果客户点开要等三四秒甚至打不开，引流就白费了。所以：

- **主力**：腾讯云 COS（国内节点）。
- **备用**：GitHub Pages 或 Cloudflare Pages 保留一份镜像，每周更新时顺带同步，作为主站异常时的兜底地址。

**费用参考**：标准存储与外网下行流量均按量计费，本榜这类小站（不足 1 MB 的页面 + 二维码图）月度支出通常在**几元到十几元**量级，以控制台实时资费为准。

## 二、方案甲：Cloudflare Pages（0 元，拖拽上传）

预计耗时：注册 3 分钟 + 上传 1 分钟。

1. 打开 **https://dash.cloudflare.com/sign-up**，用邮箱注册，选免费计划（Free），不需要信用卡。
2. 登录后在左侧菜单点 **Workers & Pages**。
3. 点右上角 **Create**（创建）→ 切到 **Pages** 标签页 → 选 **Upload assets**（上传资产）。
4. 在 **Project name** 里填一个名字，例如 `tradefreehot`——这个名字决定你的网址是 `https://tradefreehot.pages.dev`。
5. 把整个 **cbam-verifier-board 文件夹**（注意是文件夹本身拖进去），拖到页面上的虚线框里。
   - 必须确认三个文件都进去了：index.html、data.json、qrcode.png（如果没有 qrcode.png，先跳过，见第六节）。
6. 点 **Deploy site**（部署）。
7. 等 1–2 分钟，页面显示绿色 **Success** 和一个网址，例如 `https://tradefreehot.pages.dev`——**这就是你的网址，可以直接发给客户、放进公众号。**

**以后每周怎么更新：** 回到同一个项目 → **Create deployment** → 再把文件夹（或只拖改过的 data.json）拖进去 → Deploy。约 1 分钟。

**常见问题：**

- 拖文件夹后提示文件数为 0：说明拖的是文件夹里的文件而不是文件夹，或者浏览器不支持，换 Chrome 或 Edge。
- 部署后打开是空白：检查上传的文件里有没有 index.html（这个名字一个字都不能差，必须小写）。

## 三、方案乙：腾讯云 COS 静态网站（国内最快）

预计耗时：开通 5 分钟 + 上传 2 分钟。

1. 注册并登录 **https://cloud.tencent.com**（个人实名即可，不需要企业资质）。
2. 进入 **对象存储 COS** 控制台 → **存储桶列表** → **创建存储桶**。
   - 名称：自取，例如 `tradefreehot-125xxxxxx`
   - 地域：**选离你客户近的国内地域**（如上海、广州）
   - 访问权限：选 **公有读私有写**
3. 进入该存储桶 → **文件列表** → **上传文件**，把 **index.html**、**data.json**、**qrcode.png** 三个文件**传到根目录**（不要放在子文件夹里）。
4. 左侧点 **基础配置 → 静态网站** → 开启，把 **索引文档** 填 `index.html`，保存。
5. 页面上会给出静态网站访问地址，形如 `https://<桶名>.cos-website.<地域>.myqcloud.com`——**这个地址可以直接打开、可以直接发客户。**
6. 想更快／想用自己的域名：在存储桶里接入 CDN，自定义域名需完成域名备案（详见第五节）。

**以后每周怎么更新：** 进该存储桶 → 上传 **data.json** 覆盖同名文件 → 完成。刷新网页即可看到新数据（页面最多 5 分钟内自动刷新）。**约 10 秒。**

> 费用说明：静态站文件极小（总共不到 200 KB），存储和流量按量计费，通常每月只有几元。**具体以腾讯云控制台显示的实时资费为准。**

## 四、方案丙：GitHub Pages（0 元，每周更新最省事）

预计耗时：注册 3 分钟 + 上传 2 分钟。

1. 注册 **https://github.com**（邮箱即可）。
2. 右上角 **+** → **New repository**：
   - Repository name 填 `tradefreehot`
   - 选 **Public**（公开），勾选 **Add a README file**
   - 点 **Create repository**
3. 在仓库页面点 **Add file** → **Upload files**，把 index.html、data.json、qrcode.png 拖进去 → 下方 **Commit changes**。
4. 点仓库顶部的 **Settings** → 左侧 **Pages** → **Build and deployment**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，文件夹选 **/ (root)** → **Save**
5. 等 1–2 分钟，刷新页面，顶部会给出网址：`https://你的用户名.github.io/tradefreehot`

**以后每周怎么更新（这是本方案最大的好处）：**

1. 打开仓库里的 **data.json**
2. 点右上角的**铅笔图标**（Edit this file）
3. 直接在浏览器里改文字
4. 拉到最下面点 **Commit changes**
5. 等 1–2 分钟，**网页自动更新，全世界都在看最新版。不用重装、不用拖文件。**

> 注意：改 data.json 时，**逗号、引号一个都不能漏**。改之前建议先在网页上把这个文件的内容复制一份存到记事本，改坏了粘回来就行（GitHub 还有版本历史可以回滚）。

## 五、换成自己的域名（可选，非必需）

- 不买域名也能用：上面三种方案都会给你一个免费网址，功能完全一样。
- 想用 `www.你的品牌.com`：买域名（通常几十元／年）+ 在托管平台里绑定。
- **域名指向境外服务（Cloudflare、GitHub Pages）无需 ICP 备案；如果解析到境内 CDN（如腾讯云 CDN），则该域名需要完成 ICP 备案。** 备案流程由服务商引导，一般需要若干工作日。

## 六、几个一定会遇到的小问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 二维码位置显示虚线框和"此处替换成二维码图片" | 还没放 qrcode.png | 把你的企业微信二维码命名为 **qrcode.png**，放到同一个文件夹（或根目录），重新上传一次 |
| 网页顶部黄色胶囊"本地快照（未取到 data.json）" | 直接双击打开了 index.html；或服务器上只传了 index.html，漏了 data.json | 用网址打开；并把 data.json 一起传上去 |
| 改完数据，网页没变 | 浏览器缓存 / 页面还没到 5 分钟复查周期 | 等 5 分钟；或按 Ctrl+F5 强制刷新；或点页面上的"立即检查更新"按钮 |
| 打开是文件下载而不是网页 | 静态网站没开索引文档，或没传 index.html | 检查文件名必须是 **index.html**，静态网站索引文档也填 index.html |
| 手机上部分表格显示不完整 | 表格横向滚动 | 已在页面做了横向滚动适配，横向滑动即可，不需要处理 |
