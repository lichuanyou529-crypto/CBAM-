# CBAM 核查机构榜单 · 自有服务器部署（OpenCloudOS）

> 适用：腾讯云 / 自有 OpenCloudOS 8 / 9（RHEL 系，用 dnf）。
> 站点是**纯静态三文件**（index.html + data.json + qrcode.png），没有构建步骤、不依赖 Node/Python 运行时，
> 因此只需要 **git + nginx** 两个包。
>
> 2026-10-16 起仓库结构：**站点三件套在仓库根目录**，工程文件都在 `site-project/`。

---

## 〇、先确认两件事

| 问题 | 影响 |
|---|---|
| 域名**已备案**了吗？ | 大陆服务器：未备案域名走 80/443 会被拦截，只能改用 8080 这类非标准端口，或先放香港/新加坡节点 |
| 服务器有**公网 IP**吗？ | 域名解析 A 记录要指向它 |

下面主流程按「已备案 + 80/443」写；未备案的替代做法在第五节。

---

## 一、安装 git 和 nginx

```bash
sudo dnf install -y git nginx firewalld policycoreutils-python-utils
```

- 如果提示 `dnf: command not found`（老版本），换成 `sudo yum install -y ...`，包名一样。
- `git`：拉代码用；`nginx`：做静态站点；`firewalld`：放行端口；`policycoreutils-python-utils`：提供 SELinux 的 `semanage`。
- 验证：

```bash
git --version
nginx -v
sudo systemctl enable --now nginx
```

装完直接访问 `http://服务器IP` 应看到 nginx 欢迎页，说明服务起来了。

---

## 二、拉取代码

### 2.1 方式 A：直接 clone（仓库目前是公有的，无需账号密码）

```bash
sudo mkdir -p /var/www
sudo git clone https://github.com/lichuanyou529-crypto/CBAM-.git /var/www/cbam

# 确认三件套在根目录
ls /var/www/cbam
# 应看到：index.html  data.json  qrcode.png  site-project  TradeFreeHOT-方案  _src ...
```

> 若之后把仓库改回私有，需要带令牌 clone：
> `sudo git clone https://<GitHub用户名>:<个人访问令牌>@github.com/lichuanyou529-crypto/CBAM-.git /var/www/cbam`
> 令牌在 GitHub → Settings → Developer settings → Personal access tokens 生成，勾选 `repo` 权限。

> 若仓库改过名，GitHub 会自动跳转旧地址，此命令不用改。

### 2.2 建立"只含站点"的发布目录（重要）

**不要**直接把 nginx 的根目录指向 `/var/www/cbam`——那样 `site-project/`、
`TradeFreeHOT-方案/` 里的内部方案文档也会变成能被任意访问的网页。

用一个只放三件套的发布目录：

```bash
sudo mkdir -p /var/www/cbam-site
sudo cp /var/www/cbam/index.html /var/www/cbam/data.json /var/www/cbam/qrcode.png /var/www/cbam-site/
sudo chown -R root:root /var/www/cbam-site
sudo chmod -R 755 /var/www/cbam-site
ls -l /var/www/cbam-site
```

## 三、配置 nginx

新建 `/etc/nginx/conf.d/cbam.conf`（把 `cbam.example.com` 换成你的域名）：

```bash
sudo vi /etc/nginx/conf.d/cbam.conf
```

```nginx
server {
    listen       80;
    listen       [::]:80;
    server_name  cbam.example.com;          # ← 改成你的域名；没有域名就先写服务器公网 IP

    root   /var/www/cbam-site;
    index  index.html;
    charset utf-8;

    # data.json 是网页每 5 分钟复查的对象，禁止任何缓存，避免读到旧数据
    location = /data.json {
        add_header Cache-Control "no-store, no-cache, must-revalidate" always;
        expires -1;
    }

    # 页面本体也建议不缓存，保证每周更新后读者立刻看到新版
    location = /index.html {
        add_header Cache-Control "no-cache" always;
    }

    location / {
        try_files $uri $uri/ =404;
    }

    # 站点根目录只应有这三个文件；顺手把仓库内部目录全部关掉（双保险）
    location ~ ^/(site-project|TradeFreeHOT|_src|_tmp|dist)/ {
        return 404;
    }

    access_log /var/log/nginx/cbam.access.log;
    error_log  /var/log/nginx/cbam.error.log;
}
```

关掉默认站点（避免抢占 80），然后检查并重载：

```bash
sudo rm -f /etc/nginx/conf.d/default.conf      # 若存在
sudo nginx -t                                   # 语法检查，必须 success
sudo systemctl reload nginx
```

### SELinux 放行（RHEL 系必做，否则 403 Forbidden）

OpenCloudOS 默认开启 SELinux，nginx 读不到 `/var/www` 下"语境不对"的文件：

```bash
sudo semanage fcontext -a -t httpd_sys_content_t "/var/www/cbam-site(/.*)?"
sudo restorecon -Rv /var/www/cbam-site
```

### 放行防火墙

```bash
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
```

> 云服务器还要在**云厂商控制台的安全组**里放行 80 / 443 —— 这一步最常被漏掉。

### 本机自测

```bash
curl -I http://127.0.0.1/
curl -s http://127.0.0.1/data.json | head -c 200
```

## 四、配置域名访问

### 4.1 加解析记录

在域名 DNS 管理页添加一条 **A 记录**：

| 主机记录 | 记录类型 | 记录值 |
|---|---|---|
| `cbam`（或 `@` 要用主域名） | A | 服务器公网 IP |

生效通常几分钟到十分钟。验证：

```bash
dig +short cbam.example.com     # 或 nslookup cbam.example.com
# 返回的应是你的服务器公网 IP
```

### 4.2 验通

```bash
curl -I http://cbam.example.com/
# 期望：HTTP/1.1 200 OK
```

浏览器打开 `http://cbam.example.com/`，页面顶部胶囊应显示**绿色**「已连接线上数据」。

## 五、未备案怎么办

大陆服务器的 80 / 443 对未备案域名是拦截状态，两条可行路径：

**路径 1：先用非标准端口跑起来（当天可用）**

把上面 nginx 配置的 `listen 80;` 改成 `listen 8080;`，防火墙放行 8080：

```bash
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

访问 `http://服务器IP:8080/` 或 `http://你的域名:8080/`。**这种方法不需要备案**，
可以先用起来、先把内容发出去了，同时并行提交备案。

**路径 2：换到香港 / 新加坡节点**，无需备案，但国内访问速度不如大陆节点。

**备案本身**：在服务器所属云厂商的备案系统提交（腾讯云 → 备案控制台），
需营业执照、法人证件、网站负责人核验等，周期约 **10–20 个工作日**。备案通过后再把端口改回 80/443。

## 六、配 HTTPS（备案通过后）

```bash
sudo dnf install -y certbot python3-certbot-nginx
sudo certbot --nginx -d cbam.example.com
```

certbot 会自动改写 nginx 配置并申请续期。若仓库里找不到 certbot（OpenCloudOS 源不全），用 acme.sh：

```bash
curl https://get.acme.sh | sh -s email=你的邮箱@example.com
~/.acme.sh/acme.sh --issue -d cbam.example.com --webroot /var/www/cbam-site
```

> HTTP-01 校验需要域名 80 端口能从公网访问，所以**必须先备案 + 解析生效**。

## 七、日常更新（每周一次，一条命令）

站点数据每周一更新后，服务器只需重新拉取并覆盖发布目录：

```bash
cd /var/www/cbam && sudo git pull --ff-only && sudo cp index.html data.json qrcode.png /var/www/cbam-site/ && sudo restorecon -Rv /var/www/cbam-site
```

做成脚本更省事：

```bash
sudo tee /usr/local/bin/cbam-update >/dev/null <<'EOF'
#!/bin/bash
set -e
cd /var/www/cbam
git pull --ff-only
cp index.html data.json qrcode.png /var/www/cbam-site/
restorecon -Rv /var/www/cbam-site >/dev/null
echo "$(date '+%F %T') 已更新到 $(git rev-parse --short HEAD)"
EOF
sudo chmod +x /usr/local/bin/cbam-update
```

以后只需 `sudo cbam-update`。

### 想让服务器自动跟版（可选）

在服务器上挂一条定时任务，每天自动拉一次：

```bash
sudo crontab -e
# 加入下面一行：每天 09:30 自动更新
30 9 * * * /usr/local/bin/cbam-update >> /var/log/cbam-update.log 2>&1
```

这样「每周一自动化改 data.json → 推 GitHub → 服务器次日 09:30 自动拉取」整条链路无人值守。

> 更实时可以配 GitHub Webhook + 一个接收脚本，但增加了维护成本，
> 对周更频率的内容没必要。

## 八、故障排查速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 403 Forbidden | SELinux 语境不对 | 重跑 `semanage fcontext` + `restorecon -Rv /var/www/cbam-site` |
| 502 / 404 | root 路径写错，或 `/etc/nginx/conf.d/default.conf` 还在抢占 | `nginx -t` 看实际生效配置，删掉默认站点 |
| 外网打不开、本机 curl 正常 | 云厂商**安全组**没放行 | 控制台安全组加 80/443 |
| 域名打不开但 IP 可以 | DNS 没生效或 A 记录写错 | `dig +short 域名` 核对 |
| 页面显示黄色「本地快照」 | `data.json` 取不到 | 确认 `/var/www/cbam-site/data.json` 存在且可读；**不要**双击本地文件打开 |
| 改了 data.json 页面没变 | 浏览器/CDN 缓存 | 已用 `?_=时间戳` + `no-store` 绕过；必要时清 CDN 缓存 |

## 九、几个要点

1. **发布目录只放三件套**。仓库整体 clone 到 `/var/www/cbam` 便于 `git pull`，
   但对外只暴露 `/var/www/cbam-site`，内部方案文档不会变成网页。
2. **必须用 http(s) 访问**。直接双击本地 `index.html`（file://）浏览器不许 fetch 本地 json，
   页面会回退到内置快照（胶囊变黄）。
3. **改数据只改 `data.json`**，`index.html` 由脚本自动同步内置快照，不用手改。
4. 三个文件**要一起更新**，漏传 `qrcode.png` 页脚二维码会变成占位框。
